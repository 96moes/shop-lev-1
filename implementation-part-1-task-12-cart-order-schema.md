# Task 12: Define the cart and order schema

## Goal

Define Prisma models for shopping carts and orders.

## Work

Add Prisma models and relationships for:

- `carts` — customer shopping carts
- `orders` — customer orders
- `order_items` — order line items

Relate the models to users and products as appropriate.

## Done when

- [ ] All three models are present in the Prisma schema.
- [ ] Relationships between users, carts, orders, order items, and products validate.
