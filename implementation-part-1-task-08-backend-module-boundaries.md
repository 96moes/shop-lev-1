# Task 8: Create backend feature-module boundaries

## Goal

Organize backend code by feature.

## Work

Create these directories under `backend/src/modules`:

- `auth/`
- `users/`
- `products/`
- `categories/`
- `cart/`
- `orders/`
- `payments/`

Also create `backend/src/common/`.

## Done when

- [ ] All listed feature directories exist.
- [ ] `backend/src/common/` exists.
- [ ] The generated backend application still starts.
