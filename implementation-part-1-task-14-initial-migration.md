# Task 14: Create the initial database migration

## Goal

Apply the Prisma schema to the development database through a migration.

## Work

- Generate and apply the initial Prisma migration.
- Regenerate the Prisma client if required by the selected Prisma version.

## Done when

- [ ] The migration completes successfully.
- [ ] The database contains the modeled tables.
- [ ] The generated Prisma client is usable by the backend.
