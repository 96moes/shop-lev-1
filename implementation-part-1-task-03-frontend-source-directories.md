# Task 3: Create frontend source directories

## Goal

Create the directories that will organize frontend code.

## Work

Create these directories under `frontend/src`:

- `pages/`
- `components/`
- `routes/`
- `services/`
- `hooks/`

## Done when

- [ ] All five directories exist under `frontend/src`.
- [ ] The frontend still starts successfully.
