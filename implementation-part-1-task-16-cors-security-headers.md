# Task 16: Configure CORS and secure headers

## Goal

Configure cross-origin requests for development and add secure HTTP headers.

## Work

- Configure CORS to allow the frontend development origin.
- Add and configure Helmet for secure HTTP response headers.

## Done when

- [ ] Requests from the configured frontend origin are allowed.
- [ ] Backend responses include Helmet security headers.
