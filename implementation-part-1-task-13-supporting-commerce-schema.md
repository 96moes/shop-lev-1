# Task 13: Define supporting commerce schema

## Goal

Complete the core data model with supporting commerce features.

## Work

Add Prisma models and relationships for:

- `payments` — payment transactions
- `addresses` — shipping addresses
- `coupons` — discount codes
- `reviews` — product ratings and reviews
- `wishlists` — saved products per user

## Done when

- [ ] All five supporting models are present.
- [ ] Relevant user, product, and order relationships are defined.
- [ ] Prisma validates the complete schema.
