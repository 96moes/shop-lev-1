# Task 11: Define the user and catalog schema

## Goal

Define the initial Prisma models for users and the product catalog.

## Work

Add Prisma models and relationships for:

- `users` — customer and admin accounts
- `categories` — product categories
- `products` — product catalog
- `product_images` — product images associated with products

## Done when

- [ ] All four models are present in the Prisma schema.
- [ ] Required relationships are defined.
- [ ] Prisma validates the schema.
