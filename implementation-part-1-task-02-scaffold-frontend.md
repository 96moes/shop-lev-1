# Task 2: Scaffold the frontend

## Goal

Create the initial frontend application.

## Work

- Scaffold a React application with Vite and TypeScript in `frontend`.
- Confirm the application entry point is `frontend/src/main.tsx`.

## Done when

- [ ] The Vite React TypeScript application is in `frontend/`.
- [ ] The frontend development server starts and displays its starter page.
