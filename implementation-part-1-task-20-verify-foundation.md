# Task 20: Verify the foundation

## Goal

Confirm the application foundation is ready for Part 2.

## Work

- Start the frontend and backend independently.
- Confirm PostgreSQL connectivity and that migrations are applied.
- Confirm Swagger, request validation, CORS, and Helmet are active.
- Check that no real credentials or secrets are committed.

## Done when

- [ ] The frontend starts successfully.
- [ ] The backend starts successfully.
- [ ] PostgreSQL connectivity and migrations succeed.
- [ ] Swagger, validation, CORS, and Helmet are verified.
- [ ] No real credentials or secrets are committed.
