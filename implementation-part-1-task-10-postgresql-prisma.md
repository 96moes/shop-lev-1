# Task 10: Configure PostgreSQL and Prisma

## Goal

Connect the backend's Prisma setup to a local PostgreSQL database.

## Work

- Install or provision PostgreSQL for local development.
- Configure Prisma to use PostgreSQL.
- Add a backend `DATABASE_URL` environment variable with the local connection string.

## Done when

- [ ] PostgreSQL is available for local development.
- [ ] Prisma is configured for PostgreSQL.
- [ ] Prisma can connect using the environment variable.
- [ ] Real credentials and secrets are not committed.
